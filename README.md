# AI-AGENT

This repository is worked on by an autonomous agent (**lyy123-agent**),
scheduled and operated through [dsh-superagent](https://github.com/deepseek-ai/dsh-superagent-prototype).

## How to ask for work

Open an Issue, or comment on an existing Issue, and mention the agent:

```
@lyy123-agent <what you want it to do>
```

The agent acknowledges the request, works in its own session and worktree,
and replies in the same thread, usually with a pull request.
